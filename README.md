## Overview

*Reikai Monogatari* (霊界物語, *Tales of the Spirit World*) is an epic spiritual and literary work dictated by **Onisaburo Deguchi** (出口王仁三郎, 1871–1948) between 1921 and 1935, spanning **81 volumes across 83 books** (approx. 9.84 million classical Japanese characters).

This repository hosts the **complete unabridged bilingual publication**:
1. **Classical Japanese (原文・底本)** with original ruby and poetic structures faithfully preserved.
2. **Modern Japanese (現代日本語直訳)**: Strict 1-to-1 direct translation honoring the concise, dignified prose without decorative paraphrasing.
3. **Literary English (文芸英訳)**: Dignified, faithful translation suitable for comparative religion, mythic literature, and academic study.
